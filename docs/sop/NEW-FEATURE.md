# New Feature

1. Start from a Ready Story; if none exists, use `REQUIREMENT-INTAKE.md` first.
2. Read all Story `Required Reads`, linked ADRs/specs and dependency outcomes.
3. Define the smallest user-reachable or technically verifiable slice; avoid speculative abstractions.
4. Keep Agent Tool schemas semantic/coarse-grained and provider interfaces functional.
5. Preserve original-media immutability and asynchronous artifact validity.
6. Add automated tests for the changed behavior/risk and manual visual evidence when GUI/media quality cannot be proved structurally.
7. Update user-facing docs with observable behavior in the same Story.
8. Synchronize Story, Epic and iteration state before claiming completion.
