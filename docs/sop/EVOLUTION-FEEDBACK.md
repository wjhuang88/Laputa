# Evolution Feedback

Write a lesson to `EVOLUTION.md` when a corrected omission, repeated failure, newly discovered project trap, regression pattern, planning drift, or unexpectedly successful workaround is likely to recur.

Use this entry shape:

```markdown
## EVO-NNN — Short title
- Trigger:
- Symptom:
- Cause:
- Remedy:
- Prevention:
- Promotion target: AGENTS.md / SOP / test / ADR / none
```

If the lesson implies a mandatory current rule, promote that rule into `AGENTS.md`, the owning SOP, or an automated check; do not rely on history alone. Maintain the lesson index as entries accumulate.
