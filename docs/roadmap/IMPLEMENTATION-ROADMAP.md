# Laputa Implementation Roadmap

The roadmap sequences product outcomes. Executable work lives in backlog Stories; do not implement roadmap bullets directly.

## Stage 0 — Governance and architecture baseline

- Product structure, requirements, boundaries, ADRs and MVP Epic established.
- No claim of product behavior yet.

## Stage 1 — Safe project world

Deliver LAPUTA-001-A: runnable desktop shell, project persistence boundary and non-destructive media import. The first runnable artifact should let a user create/reopen a project and see imported media.

## Stage 2 — Understanding and first cut

Deliver LAPUTA-001-B/C/D: functional media understanding, embedded Talos tool loop, initial timeline state, preview and scene strip. This is the first “one sentence → visible first cut” milestone.

## Stage 3 — Generative enhancement and revision

Deliver LAPUTA-001-E/F: photo animation/generative derivative path plus selection-scoped natural-language/direct revisions and locks.

## Stage 4 — Critic and integrated MVP closure

Deliver LAPUTA-001-G/H: bounded critique/repair, reopen/continue, final export and complete end-to-end fixture acceptance.

## After V0.1

Candidates require proposal/refinement before becoming Stories: local/open model adapters, richer deterministic effects, advanced timeline, semantic retrieval at scale, platform publishing, mobile, cloud sync/collaboration and provider routing optimization.
