# Laputa Design References

This directory stores approved visual/interaction direction and repository-resident design evidence.

## Current baseline

- [UI/UX & Visual Vision v0.1](UI-UX-VISION-v0.1.md)
- [Home mockup](assets/v0.1/01-home.webp)
- [Empty project / import mockup](assets/v0.1/02-import.webp)
- [First-cut workspace mockup](assets/v0.1/03-workspace.webp)

The repository keeps compact 800×500 WebP renders derived from the approved full-resolution mockups. They are intended for implementation guidance and review, not pixel-perfect acceptance.

## Governance

- Product behavior and acceptance remain owned by `docs/reference/PRODUCT-REQUIREMENTS-v0.1.md` and active Stories.
- Design references define visual hierarchy, density, interaction direction and shared visual language; screenshots are not pixel-perfect contracts.
- Approved changes to the V0.1 UI direction must update `UI-UX-VISION-v0.1.md` and any affected active Story. Behavior changes must also follow requirement/change control.
- Do not implement directly from an image without reading the owning Story and product requirements.
